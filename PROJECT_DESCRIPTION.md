# EV Charging Station Locator (EVLiter)

**Role:** Frontend Engineer / Full-Stack Developer

**Description:** As a Software Engineer, I contributed to the development and maintenance of EVLiter, a comprehensive electric vehicle (EV) charging station locator platform designed to streamline EV charging management, station discovery, and intelligent charging recommendations. The system includes modules for AI-powered car recognition, real-time charging station mapping, smart charging advisor with cost and time optimization, charging session tracking and analytics, user authentication and authorization, and an administrative dashboard for station management and system analytics. My responsibilities included implementing new features, enhancing existing functionalities, bug fixing, performance optimization, and ensuring the system's reliability, security, and seamless integration with external services including AI APIs and mapping services.

**Technologies and tools used:**

• **React 19 with TypeScript**: Utilized for frontend development to ensure type-safe, robust, and scalable user interface components aligned with modern web development standards.

• **Vite**: Employed as the build tool and development server, offering fast hot module replacement (HMR) and optimized production builds for enhanced developer experience and application performance.

• **Tailwind CSS**: Implemented for utility-first styling and responsive design, enabling rapid UI development and consistent design system across the application.

• **Radix UI**: Integrated for accessible, unstyled UI primitives including dialogs, dropdowns, tabs, and form components, ensuring WCAG compliance and customizable component architecture.

• **Zustand**: Used for lightweight state management, providing efficient global state handling for user authentication, charging sessions, and application preferences without the overhead of complex state management libraries.

• **TanStack Query (React Query)**: Implemented for server state management, data fetching, caching, and synchronization, ensuring optimal API interaction patterns and reducing unnecessary network requests.

• **React Hook Form with Zod**: Utilized for form management and validation, providing type-safe form handling, efficient re-renders, and comprehensive input validation schemas.

• **React Router v7**: Employed for client-side routing and navigation, enabling single-page application (SPA) architecture with protected routes and role-based access control.

• **Axios**: Integrated for HTTP client functionality with interceptors for automatic token refresh, request/response transformation, and centralized error handling.

• **Google Maps JavaScript API**: Utilized for interactive mapping, geocoding, and location services, enabling real-time visualization of charging stations with custom markers, info windows, and route planning capabilities.

• **OpenAI API / Claude API**: Integrated for AI-powered car recognition and intelligent charging recommendations, analyzing vehicle specifications, charging requirements, and optimizing charging decisions based on cost, time, and distance factors.

• **JSON Web Tokens (JWT)**: Implemented for secure authentication and authorization, ensuring secure access control to API endpoints with automatic token refresh mechanisms.

• **Express.js**: Used for backend server development, providing RESTful API endpoints for charging station data, user management, authentication, and integration with external services.

• **Mock Service Worker (MSW)**: Employed for API mocking and testing during development, enabling frontend development to proceed independently of backend availability and facilitating comprehensive testing scenarios.

• **XLSX (SheetJS)**: Integrated for Excel file processing and data import functionality, allowing users to upload and process charging station data in bulk.

• **Git**: Utilized for version control, enabling seamless collaboration, code review, and version tracking within the React and TypeScript development environment.
